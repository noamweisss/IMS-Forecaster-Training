## Step-by-step

### Phase 1 — Subdivide and extract

The source files are currently all in one folder. Subdivide first:

```
mkdir courses/aviation-weather/source_files/module-2
```

Move sources 05 through 12 (filenames listed above) into that subfolder. **Do not move sources 01–04** — they belong to Module 1 and are already done.

Then run:

```
python pipeline/extract_sources.py \
    --input  courses/aviation-weather/source_files/module-2 \
    --output courses/aviation-weather/module-2/_extraction.json
```

### Phase 2 — Design and author

Read the extraction JSON. Then, following `docs/lesson_spec.md` exactly, produce:

- `courses/aviation-weather/module-2/module_structure.json` — the blueprint (5–6 lessons, objectives, key concepts, visual descriptions, quiz plan)
- `courses/aviation-weather/module-2/00_module_overview_moodle.html` — module overview body fragment
- `courses/aviation-weather/module-2/lessons/NN_<slug>_moodle.html` — each lesson as a body fragment with `<style>` block + `.ims-lesson` wrapper + inline SVG diagrams + callouts + lesson summary
- `courses/aviation-weather/module-2/lessons/NN_<slug>_quiz.xml` — each lesson's quiz (4–8 application-level questions in Moodle XML format)

Re-read the "Common mistakes to avoid" section at the bottom of `docs/lesson_spec.md` before you start writing HTML. The two biggest gotchas are forgetting the leading `<style>` block in each fragment, and accidentally writing `fill="var(--accent)"` inside an SVG attribute.

### Phase 3 — Finalize

After all lessons + quizzes + overview are written:

```
python pipeline/finalize_module.py --module courses/aviation-weather/module-2
```

This combines the quiz XMLs, embeds any images you reference (none expected at this stage — see below), builds the combined Moodle page, and writes the module's README and IMAGES_TO_SOURCE.md.

### Phase 4 — Images (only if you flag any)

If you used any `<div class="image-needed" ...>` placeholders for real photographs, the `finalize` step will list them in `courses/aviation-weather/module-2/IMAGES_TO_SOURCE.md`. Stop there and let me know what's needed — I'll source the photos and run `finalize_module.py` again to embed them.

For Module 2, most concepts (turbulence, icing, CB clouds, wind shear, fog, haze) can be illustrated with SVG diagrams. Reserve `image-needed` placeholders for things genuinely impossible to draw — e.g. "satellite image of a specific named storm event", "photo of cockpit windshield with severe icing". Don't flag generic things you could diagram.
