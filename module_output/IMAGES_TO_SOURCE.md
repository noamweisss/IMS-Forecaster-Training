# Images to Source

Below is the concentrated list of all the images and illustrations needed for Module 1, based on the placeholders in the lesson pages.

## Directory Structure

To integrate these images smoothly, please create an `images` folder inside your `lessons` directory:
`./module_output/lessons/images/`

Save your images in this folder using the exact filenames specified below.

## Required Images

### Lesson 1: International Regulatory Frameworks
- **Description:** Photograph of the UN headquarters or a joint WMO/ICAO assembly to establish the international context.
- **Save as:** `wmo_icao_assembly.jpg` (or `.png`)
- **Integration:** In `01_international_regulatory_frameworks.html`, replace the `<div class="image-needed">...</div>` with:
  ```html
  <figure>
    <img src="images/wmo_icao_assembly.jpg" alt="WMO and ICAO assembly" style="width:100%; border-radius:8px;">
  </figure>
  ```
